### 🚀 What I've Been Building

**🔹 Aawaz — Secure Backend for Phishing & Fake QR Detection**
A team hackathon project focused on security, privacy, and misinformation. I designed and built the backend: a phishing URL scanner that returns a risk score and Safe / Suspicious / Dangerous rating, and a fake-QR detector that decodes uploaded QR images and checks the extracted URL through the same engine.
Stack: `FastAPI` · `Python` · `SQLAlchemy` · `PostgreSQL/SQLite` · `Docker` · `JWT` · `Argon2`

**🔹 Paaila (पाइला) — Nepal Tourism Web App**
Built for the Government Tourism Hackathon 2026. I cleaned and structured the project's dataset — tourist sites, hotels, restaurants, and emergency contacts across Nepal — fixed location coordinates, and built the backend with Supabase while a teammate handled the Vue frontend.

**🔹 Shortest Path Finder (Dijkstra's Algorithm)**
A Python application that lets users click cities on a map of Nepal and computes the shortest route between them, using NetworkX, Matplotlib, Contextily, and a priority-queue implementation of Dijkstra's algorithm.

**🔹 Travel Recommendation App**
A full-stack project using React, FastAPI, and PostgreSQL, with the Gemini API powering AI-generated travel recommendations.

**🔹 Password Manager**
A terminal-based password manager in Python. Stores credentials locally in JSON, with a built-in password generator, search, and a master-password login secured with SHA-256 hashing.

**🔹 Real Estate Management System**
A console-based C++ application for managing property, buyer, and seller records using file handling and object-oriented programming.
